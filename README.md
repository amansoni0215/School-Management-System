# 🎓 School Management System

A School Management System built using **Python, Object-Oriented Programming (OOP), JSON, Pandas, and Streamlit**.

This project provides an interactive dashboard to manage student and teacher records, maintain academic grades, and analyze student performance.

## 🚀 Features

- Dashboard with student and teacher statistics
- Student registration
- Teacher registration
- Add and manage student grades
- View student details and academic performance
- View teacher details
- Automatic average marks calculation
- Email validation
- Duplicate roll number and employee ID checking
- JSON-based data storage
- Five different dashboard themes

## 🛠️ Technologies Used

## ⚙️ Installation and Setup

### 1. Clone Repository

```bash
git clone https://github.com/amansoni0215/School-Management-System.git
```

### 2. Open Project Folder

```bash
cd School-Management-System
```

### 3. Install Dependencies

```bash
pip install -r requirements.txt
```

### 4. Run Application

```bash
streamlit run app.py
```
